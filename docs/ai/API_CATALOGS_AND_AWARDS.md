# API: Catalogs and Awards

Task router for the shared title catalog, Oscars, Golden Globes, and award-recognition lookup. Shared paging, errors, and access modes are in [API contracts](API_CONTRACTS.md); cross-layer flow is in [Architecture](ARCHITECTURE.md).

## Client-visible rules

- When access enforcement is enabled, catalog and award reads require an active linked user or administrator; manual Golden Globes IMDb linking requires an administrator. Open mode makes these routes unprotected, so keep the API within its configured loopback or trusted-network boundary. See [access modes](API_CONTRACTS.md#access-modes).
- The RSS catalog contains `torrent_movies` with at least one `torrent_releases` row. Its numeric IDs identify catalog records, not Oscar or Golden Globes source records.
- `GET /api/catalog/genres` lists the distinct genres attached to visible torrent-catalog titles. Repeated `genres` query parameters filter for titles matching any selected genre; the singular `genre` parameter remains supported for existing clients.
- `GET /api/catalog/rss/{profileId}` returns the latest cached snapshot, including `cachedAt`, each source URL, parsed entries, and the original XML body. It does not contact RSS sources; `cachedAt` is `null` when the profile has not been cached.
- `POST /api/catalog/rss/{profileId}/refresh` fetches enabled sources one at a time, parses them, persists the snapshot, and returns it with its cache timestamp. The shared RSS transport also serializes feed requests from concurrent callers within one API process. The newest five snapshots are retained per profile. Each feed includes `fetchDurationMs` for transport fetch and response validation, and `parseDurationMs` for RSS/Atom entry parsing; both durations are in milliseconds.
- `/api/oscars` returns source-owned `oscar_movies`; its `id` identifies that Oscar record, and an IMDb match is optional. Provider metadata comes only from `imdb_titles`, so unmatched records retain their Oscar title and nomination facts without provider metadata.
- Golden Globes catalog rows are grouped by title, year, and nominee type; both movie and series records are retained. IMDb links and provider metadata are shared through `imdb_titles`.
- Award recognition lookup combines Oscar and Golden Globes records by IMDb ID; it does not perform title-only association or provider lookup. `/api/titles/{id}/oscars` resolves the RSS catalog movie and looks up Oscar records through its IMDb ID.
- A manual Golden Globes IMDb link is pinned to its nomination group and remains selected after provider failure. Clearing the link returns the group to automatic matching. Automatic matching is type-strict; manual links can retain an IMDb title whose media type differs from the nomination type.
- Torrent title IMDb matching is user-directed: `POST /api/titles/{id}/imdb-candidates?page=N` and `POST /api/parse-logs/{id}/imdb-candidates?page=N` accept a JSON `{ "title": "..." }` search title (pages 1-100), while the corresponding `/imdb-candidate` endpoints accept `{ "imdbId": "tt..." }` and load that exact record from OMDb. Both return candidates for confirmation; `/imdb-match` applies a selected IMDb ID after fetching its full metadata, using that metadata's title and year when the feed title cannot be parsed. Applying an ID already used by another torrent title merges that title's releases; applying it from a parse log resolves all unresolved entries with the same normalized torrent URL. A newer log with a different URL still prevents applying a stale match; superseded logs are hidden from failed/unresolved views; closing the candidate dialog makes no change.
- `DELETE /api/titles/{id}?deleteImdbInfo=true|false` removes the torrent catalog title, its releases, and their RSS processing states. The optional flag defaults to `false`; when `true`, canonical `imdb_titles` metadata is removed only if no other torrent, Oscar, Golden Globes, favorite, or personal-rating record references it. The response is `{ "imdbInfoDeleted": boolean }`. When access enforcement is enabled, deletion requires an administrator.
